BedWars 服务器整合包 常见问题（FAQ）
版本：v2.2.0
适用：Paper 1.21.4 / BedWars1058 25.5 / Java 21

==================================================
一、启动与开服
==================================================

Q1：双击“启动面板.exe”没有反应？
A：本版本是免 Python 独立版，不需要安装 Python。
   如果没反应，依次检查：
   1. 确认是从整合包根目录双击“启动面板.exe”
   2. 是否有杀毒软件误拦截 panel\ServerPanel.exe
   3. 解压路径不要太深，避免中文/特殊字符
   4. 仍不行可直接双击 panel\ServerPanel.exe 测试

Q2：面板打不开，或者提示端口被占用？
A：面板默认使用 127.0.0.1:8765。
   如果已经有一个面板在运行，新的启动器会直接打开已有面板，
   不会再启动第二个进程，也不会再占用 8766/8767。
   如果 8765 被其他软件占用：
   打开 panel\panel_config.json，把 panel_port 改成 8766 等空闲端口，
   然后重新启动面板。

Q3：面板里的“服务器目录”不对，显示成 F:\bw？
A：新版面板会自动识别解压目录，一般不会再出现。
   如果仍然不对：
   1. 打开面板 → 面板设置
   2. 把“服务器目录”改成当前整合包根目录
   3. 保存设置并重启面板
   注意：不要使用旧包里的快捷方式，旧快捷方式可能指向 F:\bw。

Q4：玩家管理里还有以前的玩家数据？
A：先确认面板底部“服务器目录”是不是当前解压目录。
   如果指向 F:\bw，说明打开的是旧面板或旧目录。
   新发布包本身不包含玩家账号、统计、白名单、封禁数据。
   用新目录重新打开面板后，玩家管理应该是空的。

Q5：提示“server.jar 不存在”？
A：为避免违反 EULA，整合包不直接附带 Paper 核心。
   在面板首页点“下载核心”，下载 Paper 1.21.4，
   文件会自动命名为 server.jar。
   也可以手动下载 Paper 1.21.4 并放到根目录，命名为 server.jar。

Q6：提示“尚未同意 EULA”？
A：在面板首页点“同意 EULA”，生成 eula.txt 后再点“开服”。

Q7：提示“找不到 Java / Java 路径无效”？
A：需要 Java 21。
   可以在面板设置里重新选择 Java 路径，
   或点“下载 Java”下载 Temurin 21。
   安装后把路径设置到：
   ...\jdk-21\bin\java.exe

==================================================
二、面板与进程
==================================================

Q8：直接叉掉浏览器页面，会关掉服务器吗？
A：不会。
   关闭浏览器页面默认只退出面板，服务器继续运行。
   需要连服务器一起关时，请点“退出面板并关服”。

Q9：怎么只退出面板，不关服？
A：点左侧导航底部的“退出面板”。
   也可以在关闭浏览器页面时确认退出。
   退出后服务器仍在后台运行，重新打开面板可以继续管理。

Q10：怎么连服务器一起关？
A：点“退出面板并关服”，面板会先关闭服务器，再退出面板。
   或者在面板首页点“关服”，只关服务器，不退出面板。

Q11：面板进程越开越多、端口变成 8766/8767？
A：旧版本会出现这种情况，新版已修复：
   - 关闭页面会正常退出面板
   - 端口被占用时只打开已有面板，不再新开
   如果电脑里还有旧面板进程：
   任务管理器 → 详细信息 → 结束 ServerPanel.exe，
   旧版本可能是命令行包含 ServerPanel.py 的 pythonw.exe。

Q12：关闭页面时没有弹确认框？
A：部分浏览器会屏蔽自动打开标签页的关闭确认。
   这种情况下页面关闭后仍会退出面板。
   如果不希望误关，建议用左侧“退出面板”按钮。

Q13：面板提示“unauthorized”？
A：面板重启后旧标签页的 token 会失效。
   新版已允许同源旧标签页正常退出。
   如果仍提示，刷新一次页面再操作即可。

Q14：修改配置后没保存就切换页面了？
A：新版会检测未保存修改：
   - 页面顶部显示“有未保存的修改”
   - 切换页面会提示是否放弃
   - 关闭页面/退出面板会再次提示
   建议每次改完先点当前页面的“保存”按钮。

三、客户端连接
==================================================

Q15：Java 版怎么进服？
A：地址填 127.0.0.1（本机）或服务器公网 IP，
   端口默认 25565。
   客户端版本支持 1.12 ~ 1.26.2，服务器核心是 1.21.4，
   低版本由 ViaVersion / ViaBackwards 兼容。

Q16：基岩版怎么进服？
A：基岩版端口默认 19132（UDP）。
   地址填服务器 IP，端口 19132。
   需要 Geyser 和 Floodgate 正常运行。

Q17：语音怎么用？
A：语音端口默认 24454（UDP）。
   客户端安装 Simple Voice Chat 模组后进入服务器即可。
   注意 25565、19132、24454 不要冲突。

Q18：进服提示登录/注册？
A：服务器使用 AuthMe 5.7。
   注册：/register 密码 密码
   登录：/login 密码
   如果进服后被传送到出生点，属于未登录状态，登录后会回到原位置。

Q19：外网进不来？
A：依次检查：
   1. 服务器是否已开服，25565 是否监听
   2. 路由器/防火墙是否映射 25565、19132、24454
   3. server.properties 的 server-port 是否正确
   4. 是否有白名单
   5. 客户端版本是否被 Via 支持

Q20：服务器显示在线但一直连接超时？
A：常见原因是端口映射只做了 TCP，没有做 UDP；
   或者公网 IP 写错、防火墙拦截。
   本机测试先用 127.0.0.1 排除网络问题。

四、玩法与插件
==================================================

Q21：怎么选队伍？
A：游戏开始前使用队伍选择器选择队伍。
   也可以使用 /zd 组队指令进行组队。

Q22：怎么组队？
A：使用 /zd 相关指令；具体参数以游戏内提示为准。
   队伍选择器和 /zd 都是为了比赛/开黑时更方便分组。

Q23：商店买同等级护甲买不了？
A：这是护甲规则：
   - 不能购买同等级或更低等级护甲
   - 死亡后护甲清空，可以重新购买
   这样防止重复购买低级护甲浪费资源。

Q24：Shift+左键买一组是什么规则？
A：Shift+左键购买可堆叠物品时，一次买满一组。
   按物品自身堆叠上限计算：
   - 末影珍珠 16 个
   - 羊毛、箭、TNT、金苹果 64 个
   钱不够或背包没空位会提前停止。
   Shift+右键仍然是原来的快捷购买添加/移除。

Q25：指南针怎么用？
A：指南针会自动指向最近的敌人。
   只有主手持指南针时才显示距离。
   Shift+右键打开快捷消息菜单，
   包含“敌人在这里”“需要支援”“速速回家”等。

Q26：基岩版玩家名字前面有 [BE] 吗？
A：有。
   Tab 列表顺序是：队伍 → [BE] → 玩家名 → 等级。
   大厅、等待、开始、游戏、旁观、结算都会显示。

Q27：TNT 提示粒子报错？
A：旧版 BedWars 在 Paper 1.21.4 会有粒子 NMS 报错，
   本包已改为纯 Bukkit 粒子实现，不再刷屏。

Q28：插件怎么更新？
A：面板 → 插件配置：
   先点“检查更新”，确认有新版本后再点更新。
   更新前先关服，旧 jar 会备份到
   plugins/_disabled/plugin-updates/。

==================================================
五、地图、数据与备份
==================================================

Q29：地图在哪里？
A：6 张地图在根目录 map_* 文件夹，
   BedWars1058 的地图备份在
   plugins/BedWars1058/Cache/map_*.zip。

Q30：发布包里有玩家数据吗？
A：公开发布包已经清理：
   - 玩家存档、统计、进度
   - AuthMe 账号库
   - 白名单、封禁库
   - LuckPerms 用户、SkinsRestorer 皮肤缓存
   - 玩家名/NPC 皮肤里的个人信息
   地图建筑和地图本身会保留。

Q31：服务器上的玩家数据还在吗？
A：发布包清理不影响服务器目录里的数据。
   服务器自己的 world/playerdata、AuthMe、白名单等仍然保留。

Q32：配置文件改坏了怎么办？
A：面板保存配置时会自动生成 .bak-时间戳 备份。
   也可以在 plugins 对应目录找 .bak 文件恢复。
   重要操作前建议整个目录备份一次。

Q33：日志在哪里？
A：服务器日志在根目录 logs/，
   面板日志在 panel/panel.log，
   旧的控制台日志可能以 console-*.log 形式存在根目录。

六、常见报错速查
==================================================

1. server.jar 不存在
   → 面板下载 Paper 1.21.4

2. 尚未同意 EULA
   → 面板点“同意 EULA”

3. Java 路径无效
   → 设置 Java 21 路径

4. 端口被占用
   → 关掉重复面板，或修改 panel_config.json 的 panel_port

5. 玩家管理显示旧数据
   → 检查面板“服务器目录”是否当前解压目录

6. 面板 unauthorized
   → 刷新页面；新版已兼容旧标签页退出

7. 关闭页面后进程还在
   → 旧版本问题；新版关闭页面会退出面板，重复进程可在任务管理器结束

8. 客户端连不上
   → 检查端口映射、白名单、客户端版本、EULA

9. 基岩版进不来
   → 检查 19132/UDP、Geyser、Floodgate

10. 登录不了
    → 检查 AuthMe 是否启用、账号是否已注册
