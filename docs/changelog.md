# 更新日志

## v2.2.0

### 开服面板

- 新增独立开服面板，支持开服、关服、EULA、Paper 核心下载
- 面板改为免 Python 独立版
- 新增服务器基本配置：端口、MOTD、server-ip、人数、视距、基岩版端口、语音端口
- 新增玩家管理：BW 等级、经验、白名单、封禁/解封
- 新增插件更新：Geyser、Floodgate、ViaVersion、ViaBackwards
- 新增资源生成器、商店编辑、地图管理
- 新增 Java 环境检测 / 切换 / Temurin 21 下载
- 自动识别解压目录，不再写死路径
- 单实例运行，不再重复占用端口
- 关闭页面默认退出面板，只关面板不关服
- 新增「退出面板」「退出面板并关服」按钮
- 新增配置未保存提醒
- 新增内置使用说明和常见问题

### 玩法

- 新增队伍选择器
- 新增 `/zd` 组队指令
- 新增白名单功能
- 新增 AdvancedBanZ 封禁系统，并接入面板
- 新增 AuthMe 5.7.0 登录系统
- 新增 Shift+左键一次购买一组可堆叠物品
- 为 BE 玩家增加 `[BE]` 前缀
- 为 BE 增加 UI 支持（实验性）
- 新增使用指南

### 修复与优化

- 修复全局聊天权限问题
- 修复发消息时后台报错
- 修复最终击杀相关后台报错
- 修复护甲购买逻辑
- 修复 28 血上限：进服与重生后保持 28 血
- 修复铁锻炉升级无效
- 修复 TNT 提示粒子在 Paper 1.21.4 的报错
- 完善中文语言：Tab、结算统计、快捷通讯等
- 更新 logo
- 发布包清理玩家数据、日志、备份和 NPC 中的玩家皮肤信息
