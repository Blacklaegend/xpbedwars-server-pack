# 高仿布吉岛 · 高版本经验起床服务器整合包

> BedWars 服务器整合包 v2.2.0  
> Java 1.12 ~ 1.26.3 · 基岩版互通 · Paper 1.21.4

一套面向高版本的经验起床服务器整合包。还原布吉岛经典玩法的同时，加入地雷、烟花、毒液球、幸运方块、重锤等大量道具与高版本武器，并配套独立开服面板、队伍选择器和完整管理功能。

## 核心特色

- 经验起床玩法：4队8人 / 8队4人，适合 4~32 人参与
- 6 张内置地图：4 张 4队8人地图 + 2 张 8队4人地图
- 丰富道具：地雷、烟花、毒液球、幸运方块、重锤等
- 魔王杯模式
- 可视队伍选择器
- `/zd` 组队指令
- 局部语音 + `/tell` 私聊
- 高版本兼容与基岩版互通
- 完整中文语言

## 开服面板

内置独立开服面板，不需要安装 Python。

| 模块 | 功能 |
|---|---|
| 开服 | 一键开服 / 关服，自动检测 server.jar、EULA、Java |
| 核心 | 面板内下载 Paper 1.21.4，不内置核心 |
| 控制台 | 内置服务器控制台，可直接输入指令 |
| 玩家管理 | BW 等级、经验、白名单、封禁/解封 |
| 插件更新 | Geyser、Floodgate、ViaVersion、ViaBackwards |
| 配置编辑 | 端口、MOTD、server-ip、人数、视距、基岩版/语音端口 |
| Java 环境 | 检测、切换、下载 Temurin 21 |
| 使用说明 | 内置开服流程、配置说明和常见问题 |
| 目录识别 | 自动识别解压目录 |
| 单实例 | 重复打开不会新增端口和后台进程 |
| 退出管理 | 退出面板 / 退出面板并关服 |
| 保存提醒 | 未保存、切换页面、退出都会提示 |

| 项目 | 说明 |

| 服务器核心 | Paper 1.21.4 |
| 基岩版 | Geyser + Floodgate |
| Java 端口 | 25565 |

| 语音端口 | 24454（UDP） |

> 基岩版必须使用独立端口，不要和 Java 版共用。

## 快速开始

1. 解压到任意目录（路径不要包含中文）
2. 安装 Java 21
3. 双击根目录 `启动面板.exe`
4. 面板自动识别当前解压目录
5. 下载 Paper 1.21.4 核心
6. 同意 EULA
7. 点击「开服」
8. 控制台输出 `Done` 后进入游戏

手动开服：

1. 下载 Paper 1.21.4，命名为 `server.jar` 放到根目录
2. 双击 `start.bat`
3. 默认分配 8GB 内存，可修改 `-Xmx8G`

## 注意事项

- 整合包不内置 Paper 核心，需自行下载并同意 EULA
- 基岩版必须使用独立端口
- 公网开服请映射 25565、19132、24454
- 1.8 仅理论兼容，实际以 Via 为准
- 指南针存在偶发抽风，属于已知问题
- BE UI 为实验性功能，建议实测
- 如遇插件报错，请先确认 Java 版本为 21
