# 配置示例

这里存放 BedWars1058 和 233BedWars 的配置示例，便于版本管理和查阅。

使用时请复制到服务器对应目录：

```text
configs/BedWars1058/  → plugins/BedWars1058/
configs/233BedWars/   → plugins/233BedWars/
```

注意：

- `config.yml` 里的服务器地址、端口、NPC、计分板等字段需要按实际环境修改
- 修改前先备份原配置
- 地图、插件 jar、玩家数据不在本仓库中
- 不同版本的插件可能有新增/删除配置项，升级插件后请对比默认配置
- 详细说明见 [../docs/configuration.md](../docs/configuration.md)
